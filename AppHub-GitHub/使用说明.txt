应用集合 · AppHub
=================

一个像手机桌面一样的应用启动器：把电脑上的应用集中在一个窗口里，点图标就能打开。


怎么打开
--------
1. 双击本文件夹里的「AppHub.exe」，会打开一个独立的应用窗口（不是浏览器标签页）。
   如果系统提示缺少 WebView2 运行时，安装微软的「Microsoft Edge WebView2 Runtime」即可；
   Windows 11 和大部分 Windows 10 已经自带。
2. 第一次启动会自动扫描开始菜单和桌面上的应用，通常只需要几秒钟。
3. 想放到桌面：点右上角「…」→「创建桌面快捷方式」。
4. 打开后默认最大化；按 F11 可以切换真正的全屏。
5. 默认已经开启开机自启动；想关闭：右上角「…」→「开机自启动：已开启」点一下即可。

窗口关闭后，后台的小服务还会安静地待着，下次打开会更快；重启电脑后会自动释放。
备用启动方式：「启动应用集合.vbs」（用 Edge 的应用窗口打开）或「启动（备用）.bat」。


怎么用
------
- 点击图标：打开应用。
- 拖动图标到另一个图标的中间：把两个应用合成一个文件夹，并让你给文件夹命名。
- 拖动图标到另一个图标的左右两侧：调整顺序；拖到文件夹图标上：放进文件夹。
- 拖动图标到列表最上沿或最下沿：列表会自动滚动。
- 点「＋ 新建文件夹」：创建分类文件夹。
- 打开文件夹后点「＋ 添加应用」：从列表里挑应用放进去。
- 右键应用：隐藏、添加到文件夹、移出文件夹、打开文件所在位置。
- 右上角「…」→「已隐藏的应用」：随时恢复隐藏的应用。
- 右上角「添加应用」：把没被扫描到的程序（.exe / .lnk）加进来。
- 右上角「…」→「外观与图标大小」：切换壁纸，拖动滑杆调整图标大小（64–128 像素，实时生效）。
- 右键应用 →「更换图标…」：挑一张图片当图标；也可以直接把图片文件拖到应用图标上。
- 右键应用 →「恢复默认图标」：换回程序原来的图标。
- 每次启动都会在后台重新扫描，新安装的应用会自动补进来。


数据与隐私
----------
- 分类、排序、隐藏和壁纸都保存在 data\state.json，只在本机，不联网。
- 备份整个 AppHub 文件夹，就等于备份了你的全部设置。


卸载
----
- 关闭窗口后，删除整个 AppHub 文件夹即可；不会影响电脑上已安装的任何应用。


运行环境
--------
- Windows 10 / 11
- Node.js（本机已安装，独立版和浏览器版都需要）
- Microsoft Edge WebView2 运行时（独立版需要，Windows 11 和大部分 Windows 10 已自带）
